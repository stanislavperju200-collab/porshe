# Porsche — Revistă Informativă Oficială

Acest repository conține o revistă informativă profesională despre compania Porsche, generată automat ca document Word (.docx).

## Conținut

```
porshe/
├── README.md                  # Instrucțiuni
├── requirements.txt           # Dependințe Python
├── revista_porsche.py         # Script de generare
├── Revista_Porsche_2026.docx  # Documentul Word generat
└── images/                    # Imagini descărcate (dacă există)
```

## Secțiunile revistei

1. **Foaie de titlu** — design elegant în stilul Porsche (negru, alb, roșu)
2. **Cuprins** — lista secțiunilor cu numere de pagini
3. **Despre Companie** — sediu, fondare, cifre cheie
4. **Istoria Porsche** — de la 1931 până în 2025
5. **Gama de Modele 2025** — 911, 718, Panamera, Cayenne, Macan, Taycan
6. **Servicii Porsche** — Exclusive Manufaktur, Approved, Financial Services etc.
7. **Pagina finală** — contact și disclaimer

## Cerințe

- Python 3.8+
- Dependințele din `requirements.txt`

## Instalare dependințe

```bash
pip install -r requirements.txt
```

## Generare document

```bash
python revista_porsche.py
```

Documentul `Revista_Porsche_2026.docx` va fi creat în același director.

## Stil și design

- Fonturi: Arial (sans-serif)
- Culori: negru (#000000), gri închis (#333333), roșu Porsche (#C50019)
- Layout minimalist, profesional, în stilul oficial Porsche
- Textul este în limba română

## Despre Porsche

Porsche AG este un producător german de automobile sportive de lux, cu sediul în Stuttgart, Germania. Fondată pe 25 aprilie 1931 de Ferdinand Porsche, compania este parte a Volkswagen Group și este renumită pentru modelele iconice 911, Cayenne, Taycan și altele.

Website oficial: [www.porsche.com](https://www.porsche.com)
